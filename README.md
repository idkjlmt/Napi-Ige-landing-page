# Napi Ige landing page

Első, statikus weboldal-tervezet a Napi Ige októberi kiadványához.

## Helyi megnyitás

A projekt gyökerében indíts egy egyszerű webszervert, például:

```powershell
python -m http.server 8080 --directory dist
```

Ezután nyisd meg a `http://localhost:8080` címet.

## A kiadvány hozzáadása

Másold a PDF-et ide:

`dist/assets/2610-NAPI-IGE-OKTOBER.pdf`

Ha a fájl még nincs a projektben, az olvasó felületéről ideiglenesen is betölthető egy PDF.
